# Folio Reader v0.1.2

第三个测试版本，将应用名称从“论文阅读器”更新为 **Folio Reader**，面向论文、书籍、财报及其他 PDF 文档。

## 本次更新

- 统一应用标题、窗口名称、安装包名称和中英文项目介绍。
- 新增 OpenRouter、智谱 GLM、小米 MiMo 服务预设，可填写自己的 API Key 和模型 ID。
- 适配 MiMo 的输出 token 参数，并关闭深度思考以优先返回阅读回答。
- 保留自定义 OpenAI 兼容服务与本地模型配置。

## 升级与数据

升级前退出旧版并备份书架。应用标识、数据库文件名和系统凭据标识保持不变，继续读取现有资料，无需迁移。macOS 上新名称的 Folio Reader.app 不会自动覆盖旧名称的应用；安装后请使用 Folio Reader，避免同时打开两个版本。

## 验证与限制

- 本机前端回归、数据库迁移与 Rust 回归测试通过，包含备份恢复及损坏文件拒绝测试。
- 服务预设已通过离线请求构造测试，实际账号调用尚未验收。
- 界面仍以中文为主；本次更名不代表完整英文界面。
- 安装包尚未配置正式发行签名及 macOS 公证。
- 各平台安装、关闭重启与持久化验收完成后才发布对应安装包。
