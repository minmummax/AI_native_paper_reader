# 论文阅读器 v0.1.1 测试版

第二次本地发版。macOS 包面向 Apple Silicon；Windows x64 构建配置已提供，Windows 安装包需在 Windows 或 GitHub Actions 中另行构建、验收。

## 本版更新

- 全新应用图标：墨绿色底、论文书页、珊瑚色书签和黄色高亮。
- 标签书脊与论文封面式书架、多标签组合筛选、阅读/年份/导入时间排序及取书动画。
- 选中文字后翻译或提问，结果保存在右侧 AI 阅读记录，支持 Markdown、公式、原文定位及备份。
- 悬浮整篇问答，在本机提取并缓存全文后选取相关证据；默认 24KB、可扩展 48KB，并显示证据覆盖范围。
- 后台模型配置、自定义 OpenAI 兼容服务、本机用量统计；密钥存入系统凭据库。
- arXiv 导入及正文搜索关闭等修复。

## 升级

先在旧版导出完整备份并退出应用。打开 DMG，将“论文阅读器.app”拖入 Applications 覆盖旧版，再启动。应用标识与 0.1.0 相同，继续使用原有资料；数据库会升级到包含 AI 用量及阅读记录的版本。

密钥不包含在资料备份中。整篇聊天目前保留在本次会话，选区翻译和提问才会写入本地历史。恢复不含 AI 阅读记录的旧备份时，历史记录会恢复为空。

## 验证与限制

本机类型检查及生产构建通过；10 个 JS 测试文件、10 个 Python 用例、13 个 Rust 用例通过（1 个在线下载测试按设计跳过）。安装包已校验 SHA-256 与 DMG 内部校验和，附 `SHA256SUMS.txt`。已确认应用包版本为 0.1.1、架构为 arm64，并引用新版 `icon.icns`。

本次为测试版候选包，并非已完成所有平台原生验收的稳定版。真实供应商、系统凭据库、原生安装/关闭重启/备份恢复全流程和 Windows 仍需验收。长论文按关键词及章节选取有限正文，回答只代表所提供的证据，不保证理解了每页内容；扫描 PDF 没有 OCR。

macOS 未完成 Developer ID 签名和公证；Windows 未配置发布者签名。详细构建步骤及验收清单见 `docs/RELEASING.md`。自动构建产物需验收后再公开发布。
