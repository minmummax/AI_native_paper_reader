# v0.1.0 安装包构建记录

- 构建类型：Rust release 优化构建；前端 TypeScript 检查及 Vite 生产构建通过。
- 架构：arm64 / Apple Silicon。
- 应用版本：0.1.0。
- 包内应用进行了 ad-hoc 本地签名，`codesign --verify --deep --strict` 通过。这不是 Developer ID 签名，未进行 Apple 公证。
- Tauri 的 DMG 脚本在当前沙盒环境失败；最终使用 macOS `hdiutil create -format UDZO` 生成包含应用、Applications 快捷方式和发行说明的安装盘。
- `hdiutil verify` 完整性验证通过；SHA-256 见同目录 SHA256SUMS.txt。
- 尚未执行另一台 Mac 的安装验收，没有上传到公开发布平台。
