# 论文阅读器 v0.1.0 测试版

适用平台：macOS Apple Silicon（M 系列），不包含 Intel Mac、Windows 或 Linux 安装包。

## 安装

打开同目录中的 DMG，将“论文阅读器.app”拖入 Applications（应用程序），退出旧版后启动新版。已有开发版使用相同应用标识符，继续使用原有本地资料；升级前建议在旧版“备份”中保存一份完整备份。

此包没有 Apple Developer ID 签名或 Apple 公证。其他电脑下载后可能受到 macOS 安全检查阻止；本版用于受控测试，不应描述为已完成正式分发认证。

## 已有功能

- 离线 PDF 导入、文件夹扫描、哈希去重、标签和收藏夹。
- 虚拟化阅读、目录与缩略图、缩放旋转、正文搜索。
- 高亮、下划线、框选、关联笔记和草稿自动恢复。
- 本地备份恢复，包括 PDF、数据库和草稿；恢复前自动备份现有资料。

不包含 AI、翻译、OCR 或云同步。加密 PDF 需要先解锁；备份恢复为整库替换，不是合并。

## 验证范围

类型检查、前端生产构建、JS/Python/Rust 自动化测试已通过；搜索及草稿完成浏览器组件交互验证。原生安装、桌面文件对话框、备份恢复全流程和其他平台仍需验收，因此标记为测试版。

正式对外发布前，还需完成 Developer ID 签名、公证和另一台 Mac 的安装/启动/导入/重开验收。
